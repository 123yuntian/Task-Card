# UI 术语表 · 前 10 条

> 三周计划 D1 产物 · 用途：跟 agent 说话时用得上；三个词记牢就够（App Shell / Token / 五态）
> 排查用：`grep` 的时候这些词就是搜索关键词

| # | 术语 | 一句话 | 记它的理由 |
|---|---|---|---|
| 1 | **App Shell**（应用外壳） | 由 **侧栏 + 顶栏 + 主区** 三块组成的固定骨架；切页面时外壳不动，只换主区里的内容 | 今天要学的就这一个词。你现在的 Task Card 还没有外壳，切换视图靠整块隐藏 |
| 2 | **Sidebar**（侧栏） | 左边那条固定导航，宽 208–240px | 你现在有一条（"看板/今日/历史/快照/设置"），但宽度是随内容撑的，没定值 |
| 3 | **Header**（顶栏） | 主区顶部那条横带，高 56px，放标题、面包屑、主操作按钮 | 你现在的"工具栏"就是它，但和标题混在一起，没分成两层 |
| 4 | **Main / Content**（主区） | 捡侧栏和顶栏剩下的地方，内容宽度封顶 1280px 居中 | 你现在直接拉满屏（`max-width: 1200px` 只加在工具栏上） |
| 5 | **Token**（设计变量） | 给一个值起名字，比如把 16px 叫 `--space-3`；改 Token = 全站跟着变 | 改一次全站生效，这就是"不用逐个文件改数字"的秘密 |
| 6 | **8pt Grid**（八点网格） | 所有间距取 8 的倍数，4px 当半格 | 你现在的间距是 15/18/20/22 混着来，看着"差一点"就是这个原因 |
| 7 | **Type Scale**（字号阶梯） | 固定 6 级：12/14/16/20/24/32，不许临时加第 7 级 | 你现在有 13/15/17/22/32 一堆散值 |
| 8 | **Breakpoint**（断点） | 屏幕宽过某个值就换布局：768 / 1024 / 1280 | 你 10/28 做的"窄屏横条"就是断点，只是没叫这个名字 |
| 9 | **五态**（States） | 一个控件有五种样子：默认 / 悬停 / 聚焦 / 禁用 / 加载 | 判断"做得完不完整"就看五态齐不齐 |
| 10 | **空态 / 加载态 / 错误态** | 没数据、等数据、出错，三种都有专门画法（空态 = 图 + 标题 + 说明 + 一个按钮） | 你现在的"今日尚未发布"就是空态雏形，但缺一个行动按钮 |
